## Projetos em destaque

### [Automatizador de Pagamentos Internacionais](https://github.com/JeremiasSantana/Automatizador_de_pagamentos_internacionais)
`Python` `MySQL` `Pandas` `Selenium` `APIs REST` `Poetry`

Pipeline end-to-end do ciclo financeiro: extrai faturas pendentes do MySQL, cruza com planilhas de clientes, consulta cotação de moedas via API, cadastra no sistema web com Selenium e atualiza o status no banco após a execução, evitando reprocessamento. Logs de acompanhamento em todas as etapas.

### [Robô de Download do Telegram + Versão Web](https://github.com/JeremiasSantana/download_videos_gurpo_telegram)
`Python` `Telethon` `FastAPI` `pytest`

Aplicação modular que baixa vídeos de grupos, grupos com tópicos, canais e conversas, com controle de duplicados, retomada de downloads e tratamento de erros por arquivo. A versão web, em FastAPI, reaproveita o mesmo núcleo, e o projeto é coberto por 51 testes automatizados.

### [Chatbot Assíncrono de Mídias — jota_botv1](https://github.com/JeremiasSantana/Bot_telegram)
`Python` `aiogram` `asyncio` `yt-dlp`

Bot de Telegram event-driven para gestão concorrente de downloads e entregas de mídia, com sanitização de URLs, conversão de arquivos via subprocessos assíncronos e logging estruturado.
